# Upstream Snapshots (archived)

<!-- Moved here in the estebanmoreno04 fork of NoahJenkins/vgc-coach. -->

These hand-written, dated regulation snapshots come from the upstream repository (NoahJenkins/vgc-coach). They were written before the fork detected the active regulation automatically.

They are **history only**:

- never use them for present-tense coaching;
- the active regulation lives in `data/current/regulation.json` (written by `tools/resolve_regulation.py`);
- the current meta lives in `data/current/snapshot.json` (written by `tools/build_snapshot.py`).

When the regulation changes, the resolver archives the previous `data/current/` data to `data/archive/<regulation id>/`, next to this folder.
